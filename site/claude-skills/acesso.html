Montagem manual

Como instalar

01 Copiar e colar

Abra o arquivo do skill, copie o conteúdo e cole direto num chat do Claude. Funciona até no plano gratuito.

02 Upload único

Suba o arquivo em Configurações → Skills. Exige plano Pro ou Max com execução de código habilitada.

03 Claude Code

Instale via linha de comando com o script do repositório: veja o passo a passo no README do GitHub.
