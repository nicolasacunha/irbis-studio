## Achados

### P2-1 · Deploy órfão exposto com identidade de template, com proposta viva no mesmo contato
A URL está no ar sob a org da IRBIS e serve título, descrição e banner do template público da
Vercel, sobre uma tela 404. Está `noindex`, então não polui busca — o risco é de link direto.

Elevado de P3 para P2 pelo cruzamento com o pipeline: existe uma proposta de Sistema
Operacional aberta com o mesmo interlocutor, fria, aguardando follow-up. Um link antigo do
projeto anterior mostrando um 404 sobre template genérico é a última coisa que deveria estar
alcançável enquanto essa proposta está em pé.

Ação sugerida: despublicar o deployment, ou trocar por uma página estática de uma linha.

Nota: `irbis.com.br/adash` é outra coisa — é o case, servido via rewrite para
`cases-hub/adash/`, e está íntegro. `/adash-demo/` está bloqueado no `robots.txt` do site.
