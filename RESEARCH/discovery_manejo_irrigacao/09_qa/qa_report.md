# Controle de qualidade

## Verificações

- [x] Brasil e exterior foram separados.
- [x] Relatos diretos, estudos e materiais promocionais foram identificados.
- [x] As alegações centrais possuem duas ou mais fontes independentes.
- [x] Contradições foram preservadas.
- [x] Percentuais de economia não foram generalizados.
- [x] O produtor não foi tratado como um perfil único.
- [x] Recomendação de solução foi marcada como hipótese a validar.
- [x] Lacunas de entrevistas e piloto foram registradas.

## Auditoria de linguagem

- “Comprovado” foi evitado quando a fonte era um caso individual.
- “Produtor” só foi usado como identidade confirmada quando a fonte o identificou ou quando o próprio participante se declarou produtor; relatos anônimos permanecem marcados.
- Materiais de fornecedores não sustentam sozinhos nenhuma alegação central.

## Veredito

A definição revisada do trabalho e do problema possui suporte suficiente para orientar entrevistas e o recorte do protótipo. Ainda não possui suporte suficiente para alegar tamanho da dor, retorno financeiro ou adoção no ICP brasileiro.
